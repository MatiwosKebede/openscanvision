## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please do **not** open a public issue.

Please report it privately by emailing:

**matiwoskebede01@gmail.com**

You can expect:
- **Acknowledgment** within 48 hours.
- **A status update** within 7 days.
- **Credit** for the discovery if you wish, after the issue is resolved.

We appreciate your responsible disclosure.
